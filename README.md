This repository is the central hub for **PPOL 652**. Throughout the week, you will work through the full lifecycle of a policy data project: from scoping a tractable question and auditing raw data to cleaning, exploring, visualizing, and defending your findings.

You'll find most of the course materials on **myCourses**, but we will also use this GitHub repository to share data, code, or resources as needed.

## Getting Started

We'll start by talking about developing a research question and selecting data sources. To facilitate that process, we've put together a list of curated datasets across a number of different topics. Start by reading [`datasets/README.md`](datasets/README.md) to explore the 6 Policy Themes, variable summaries, and links to every dataset's official source documentation.

> **Note on viewing CSV files:** GitHub's web interface truncates or blocks previews for larger CSV files. Always **download the CSV file to your computer** (click the file, then click the **Download raw file** icon in the top-right corner of the file view) or clone the repository locally to open the data in Excel, Python, or R.
